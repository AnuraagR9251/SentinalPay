**Senetinal Pay** is a complete, feature-rich, high-fidelity frontend payment web application inspired by Google Pay (GPay / Tez / UPI) built with **pure HTML5, CSS3, and JavaScript**.

> **No build steps. No `node_modules` required. Double-click `index.html` to run locally or host on GitHub Pages in 10 seconds!**

---

## 🌟 Key Features

1. **Google Pay Action Grid**:
   - Scan any QR code, Pay contacts, Pay phone number, Bank transfer, Pay UPI ID, Self transfer, Pay bills, and Check balance.
2. **Interactive 4-Digit UPI PIN Pad**:
   - Masked PIN indicators, numeric keypad with tap sound, and biometric (Face ID / Fingerprint) authentication simulation.
3. **Celebration & Sound Engine**:
   - Ascending harmonic UPI chime synthesized directly via the browser's **Web Audio API** (no missing audio assets), accompanied by full-screen `canvas-confetti`.
   - Downloadable & printable official payment receipts with generated UTR reference numbers (`SENT...`).
4. **Interactive Scratch Cards (GPay Hallmark)**:
   - Real HTML5 Canvas scratch surface. Scratch with mouse or finger to reveal cashbacks and vouchers that auto-credit to your Senetinal Wallet!
5. **QR Code Scanner & "My QR"**:
   - Live laser camera simulation with torch toggle, test presets, and personalized UPI QR code generator (`aarav@senetinal`).
6. **Bills & Utilities Hub (BBPS Simulated)**:
   - Pay Electricity, 5G Mobile Recharge, Broadband, DTH, FASTag, and Gas with 1-click checkout.
7. **Split Expenses / Group Bills**:
   - Multi-friend bill split calculator with per-person math and settlement tracking.
8. **3D Virtual Cards & Linked Banks**:
   - 3D flip card visualizer (Visa Infinite & Mastercard), freeze/unfreeze toggle, CVV reveal, and live bank balance check with UPI PIN.
9. **Transaction History & Audit Ledger**:
   - Search, filter by debits/credits/bills/rewards, spending analytics, and CSV statement export.
10. **Dual View Modes & Polish**:
    - Includes a **Mobile Device Frame Toggle** that wraps the app into a sleek smartphone mockup with Dynamic Island, plus dark/light theme switching and `localStorage` persistence.

## 🚀 How to Host on GitHub Pages (Free & Instant)

Because this project is built with standard HTML, CSS, and JS, you can host it live on the web in 3 simple steps:

### Step 1: Push to GitHub
Open PowerShell and run:
```powershell
cd C:\Users\akaha\OneDrive\Desktop\Senetinalpay

git init
git add .
git commit -m "feat: complete Senetinalpay frontend"
git branch -M main

git remote add origin https://github.com/<your-username>/Senetinalpay.git
git push -u origin main
```

### Step 2: Enable GitHub Pages
1. Go to your repository on GitHub: `https://github.com/<your-username>/Senetinalpay`
2. Click **Settings** (top tabs) -> **Pages** (left sidebar).
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**.

### Step 3: Your App is Live!
Within 1 minute, GitHub will give you a public URL like:
👉 **`https://<your-username>.github.io/Senetinalpay/`**
